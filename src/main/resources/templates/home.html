Bunny Command Redirector

How It Works

Enter commands in the format command query to be redirected to specific websites with your query.

Examples:

  • g java programming - Search Google for "java programming"
  • yt funny cats - Search YouTube for "funny cats"

You can use either:

  • Search format: /r?q=command+query
  • Direct format: /command/query
